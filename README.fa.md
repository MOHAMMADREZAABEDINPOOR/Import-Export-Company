## شروع کار

مرورگر جدید؛ Python فقط برای سرور HTTP محلی اختیاری است.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/Import-Export-Company.git
cd Import-Export-Company

python -m http.server 8000
```
